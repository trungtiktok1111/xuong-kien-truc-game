# Gói 2D SBS (đầy đủ)

Chạy `python3 build_all.py` (cần bộ nguồn SBS tại SRC trong build_all.py) để sinh toàn bộ gói đầy đủ, không cắt bớt; gói lớn tự chia phần `-pNN` (≤260 mục, ≤110 với ô 256). Bản dựng sẵn nằm ngoài kho (ổ D, thư mục "Gói 2D"); nạp bằng nút "Gói xuong-pack" và chọn nhiều tệp .zip cùng lúc.
